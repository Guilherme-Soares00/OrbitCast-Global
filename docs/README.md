# Documentos de Entrega - OrbitCast

Esta pasta reúne os arquivos de apoio para a entrega de Java/DDD do projeto OrbitCast.

## Arquivos

- `OrbitCast_Documentacao.pdf`: documentação técnica final em PDF.
- `diagramas/diagrama-arquitetura.svg`: diagrama de arquitetura em camadas.
- `diagramas/diagrama-arquitetura.png`: versão em imagem do diagrama de arquitetura.
- `diagramas/diagrama-entidade-relacionamento.svg`: diagrama entidade-relacionamento do banco.
- `diagramas/diagrama-entidade-relacionamento.png`: versão em imagem do diagrama entidade-relacionamento.

## Observações

- A API de produção está em `https://orbitcast-global-api.onrender.com`.
